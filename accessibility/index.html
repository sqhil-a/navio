Accessibility

NPCC information and participation should be usable.

Navio Pathways provides accessible HTML competition information and accepts reasonable requests related to registration, preparation, submission, presentation, and online participation.

Website design

  • Semantic headings, lists, links, and landmarks
  • Keyboard navigation and visible focus
  • Readable type and strong colour contrast
  • Responsive layouts without horizontal scrolling
  • Reduced-motion support
  • Core competition instructions available as HTML

Competition arrangements

Possible arrangements include accessible document formats, extra time for a documented event task, an adjusted presentation method, captioning-compatible delivery, a support person, or another reasonable change that preserves the essential competition criteria.

Request process

Email hello@naviopathways.com with the activity or barrier and the arrangement that would help. Send event requests by November 1 when possible so Navio can confirm the plan with the team advisor. A diagnosis or medical record is not required.
