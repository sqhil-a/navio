Accessibility

Career information should be usable in different ways.

Navio Pathways designs its program and resources for keyboard access, browser zoom, assistive technology, and flexible pacing.

Program format

The Career Clarity Program uses semantic HTML headings, lists, links, and tables. It has no time limit, required account, or mandatory input method. Students may use browser zoom, a screen reader, voice input, or copy prompts into a preferred private format.

Design commitments

  • Keyboard navigation and visible focus
  • Readable type and strong colour contrast
  • Responsive layouts without horizontal scrolling at common widths
  • Reduced-motion support
  • Core instructions available as HTML

Feedback and alternative formats

Email hello@naviopathways.com with the page, barrier, and format or support that would help. A diagnosis or medical record is not required.
